# История изменений

## 2.0.0

### Важно при обновлении
- **Скрипты в опциях больше не поддерживаются.** Перед обновлением перенесите скрипты (например, Яндекс Метрику) из опций в шаблон сайта: `script`, `style`, `iframe`, `object`, `embed`, `noscript` удаляются вместе с содержимым при первом сохранении страницы параметров.
- **PostgreSQL:** после обновления переустановите модуль (данные сохраняются) или выполните `ALTER TABLE claramente_options DROP CONSTRAINT IF EXISTS code_fk;`, иначе ошибочный внешний ключ останется и опции не будут создаваться.

### Новое
- Текстовая подсказка к параметру: хранится в `SETTINGS['hint']`, выводится после поля для встроенных и пользовательских типов, переносится миграциями.
- Тип «Число» для целых и десятичных значений с настраиваемой точностью, без округления.
- Серверная проверка значений и настроек типов (`validateValue()`, `validateSettings()`, `validateStoredValue()`): при ошибке на странице параметров не сохраняется ни одно значение, введенные данные остаются в полях.
- Готовые наборы символов строки («Только цифры» и т.п.) проверяются и на сервере.
- Безопасный HTML в значениях строк, текстов и строк (`CBXSanitizer`).
- `cm_option_set()` возвращает текст ошибки необязательным параметром `$error`.
- Офлайн-проверки: `php tests/run.php`.

### Исправления
- Проверка токена сессии при изменении данных, экранирование вывода, безопасный `unserialize`.
- Права: контентщики сохраняют значения доступных им опций, вкладки и параметры меняет только администратор.
- Миграции переносят все поля опции без потерь (кавычки, обратные слеши, переводы строк).
- Создание миграции работает на sprint.migration 5.8 и новее, совместимость со старыми версиями сохранена.
- После создания миграции выводится ее имя или текст ошибки на любой версии sprint.migration, обновление страницы не создает миграцию повторно.
- PostgreSQL: удален ошибочный внешний ключ `code_fk`, время изменения обновляется явно.
- Кэш: явно переданное время приоритетнее константы, ключ предзагрузчика разделяет код и сайт, предзагрузчик сбрасывается после изменений.
- Значения по языкам: строка не ломает опцию, пустое значение не отбрасывает заполненное.
- Дата и файл без значения не вызывают `TypeError`.
- Сущности в текстовом поле не теряются при пересохранении.
- Удаление элемента списка не сдвигает сохраненные значения.
- Уникальность пары код + сайт при сохранении параметра, проверка кода вкладки.
- Файлы удаляются вместе с опцией.
- Снятие обработчика меню при удалении модуля.
- Абстрактные наследники не регистрируются как типы.
- `cm_option_filled()` считает `"0"` заполненным, у новой опции нет кнопки «Создать миграцию».
